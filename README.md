# 桂林茶江路房屋出租展示网站

面向手机租客的纯静态中文房屋展示网站，展示普通单间、一室一厅、真实房屋照片、免费配套、位置与房东联系方式。项目无后端、无数据库、无付费 API，也不依赖运行时 CDN。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`。

## 内容维护

房屋地址、联系方式、两种户型、免费配套文案及图片清单均集中在 `src/data/site.ts`。后续修改真实信息时优先编辑该文件。

网页使用的真实照片放在：

- `public/images/building/`：房屋外观与公共过道
- `public/images/studio/`：普通单间
- `public/images/suite/`：一室一厅
- `public/images/contact/`：房东微信好友二维码（保持原图，不裁切或有损压缩）

请勿把不同户型照片混用，也不要在网站配置或代码中加入公开租金、具体房号或未经房东确认的配套参数。

## GitHub Pages 部署

1. 在 GitHub 新建仓库（例如 `guilin-rental-showcase`）。
2. 将本项目提交并推送到仓库的 `main` 分支。
3. 在仓库 `Settings → Pages → Build and deployment` 中选择 `GitHub Actions`。
4. 推送后，`.github/workflows/deploy.yml` 会自动构建并部署网站。

`vite.config.ts` 使用相对资源路径，因此可部署在用户名主页或任意仓库子路径，无需写死仓库名称。

GitHub Pages 免费且适合静态站点，但其服务条款对商业用途有限制，中国大陆及微信内置浏览器的访问稳定性也无法保证。若后续需要更稳定的国内访问，请根据实际情况选择合规的静态托管服务；本项目结构不绑定 GitHub Pages。

## 已实现功能

- 首页真实外观照片与两种户型入口
- 免费电动车停放、充电及免费宽带的集中配置与展示
- 普通单间和一室一厅实拍图库
- 点击放大、键盘切换及手机左右滑动
- 电话直拨、微信号与地址复制提示
- 房东微信好友二维码展示、点击放大及长按识别支持
- 高德地图附近位置搜索（不编造经纬度）
- 手机固定联系栏、返回顶部与响应式布局
- SEO 基础信息和 GitHub Pages 自动部署

所有房屋信息和图片均应以实际看房及房东最新确认为准。
